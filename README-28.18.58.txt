28.18.58 — إصلاح ذاتي للأجهزة والجلسات
- معالجة جذرية لحالة جهاز واحد يحتفظ بمعرف مستخدم قديم بعد تحديث/تنظيف بيانات المتصفح.
- مطابقة الجلسة بالمعرف ثم اسم المستخدم ثم الاسم، وإعادة ربطها تلقائياً بدليل المستخدمين الحالي.
- إضافة Device Recovery Guardian يعالج حالة الجلسة وإعدادات التشغيل فقط دون حذف بيانات الأعمال أو كلمات المرور.
- تشغيل المزامنة تلقائياً عند الدخول/عودة الاتصال/استئناف التطبيق.
- طلب تحديث Service Worker تلقائياً حتى لا يبقى الجهاز على ملفات تشغيل قديمة.
- لا يتم حذف أي Cache أعمال أو سجلات أو Tombstones أو إعدادات سحابية.
