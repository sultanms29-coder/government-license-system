منصة العلاقات العامة والحكومية — الإصدار 28.18.77

نطاق هذا الإصدار: تعديل إنشاء المشاريع الجديدة فقط، مع الحفاظ الكامل على بقية المنصة وبياناتها ومزامنتها وتصميم الجوال والكمبيوتر.

التعديل:
- كل مشروع جديد يُنشأ تلقائياً مع 17 مهمة قياسية مستخلصة من مشاريع القصيم بريدة والدمام الندى وأبحر الشمالية.
- تُحفظ بيانات المشروع وجميع مهامه القياسية في عملية واحدة لتصل متكاملة عبر المزامنة.
- تبدأ المهام القياسية بحالة فارغة وتظهر للمستخدم باسم «غير محددة» حتى يختار حالتها.
- يبقى مستوى المخاطر الافتراضي «عادي»، وتواريخ الاستحقاق والملاحظات والإجراءات والدعم فارغة.
- تظل إضافة أي مهمة إضافية متاحة، مع استمرار الترقيم بعد آخر مهمة.

ضمانات الاستقرار:
- لم تُعدّل المشاريع أو المهام المسجلة سابقاً بأي شكل.
- لم تتغير مفاتيح التخزين أو هيكل البيانات أو إعدادات Supabase أو آلية المزامنة.
- لم تتغير بقية الأنظمة أو صلاحيات المستخدمين أو تصميم الكمبيوتر والجوال.
- الإصدار مبني مباشرة على النسخة 28.18.76.
