منصة العلاقات العامة والحكومية — الإصدار 28.18.75

إعادة بناء مزامنة نظام متابعة الأعمال اليومية على نفس معمارية نظام متابعة التراخيص المستقرة.

ما تغير في الأعمال اليومية:
- قراءة مركزية واحدة عند فتح النظام من مساحة alandiyah-daily-work نفسها.
- دمج بيانات الجهاز مع أحدث نسخة سحابية قبل كل رفع، ثم رفع نسخة موحدة واحدة.
- قناة Supabase Realtime واحدة لإظهار التحديثات الفعلية فورًا لجميع المستخدمين.
- فحص احتياطي كل خمس دقائق يقرأ revision فقط، ولا يسحب payload إلا عند وجود تحديث أحدث.
- إزالة حلقة التثبيت القديمة ذات المحاولات الست والبث الشبكي الموازي وإعادة الدفع من كل تبويب.
- طابور محلي واحد للتعديلات غير المرسلة، ويعاد إرساله عند عودة الإنترنت أو الفحص الاحتياطي.
- دمج أي تعديلين متزامنين على مهام مختلفة قبل الرفع، مع إعادة نشر النسخة الموحدة عند الحاجة.

حماية البيانات:
- لم تتغير مساحة العمل alandiyah-daily-work.
- لم تتغير مفاتيح المهام والمستخدمين والتقييمات والسجل أو مفاتيح النسخ الاحتياطية.
- بقي دمج workflowRevision وسجل الأحداث والتنبيهات وتاريخ الاعتماد والإغلاق النهائي كما هو.
- بقيت tombstones الخاصة بحذف المهام والموظفين فعالة لمنع عودة السجلات المحذوفة.
- بقيت نسخة LAST_GOOD والحفظ المحلي قبل أي إرسال سحابي.

حماية استهلاك Supabase:
- لا يوجد سحب دوري للحمولة الكاملة أثناء الخمول.
- لا يوجد بث ثانٍ للحمولة نفسها.
- لا توجد إعادة محاولات سريعة مستمرة عند تعذر الاتصال.
- عمليات القراءة الكاملة مرتبطة فقط بفتح النظام أو وجود تعديل فعلي أو عملية حفظ ودمج.

لم تُعدّل بقية أنظمة المنصة أو صلاحياتها أو بياناتها.
