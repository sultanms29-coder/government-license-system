# منصة العلاقات العامة والحكومية — الإصدار 27.4.0

هذه هي حزمة النشر النهائية المراجعة، ولا تحتوي على نسخ تشغيلية سابقة.

## الأنظمة التشغيلية السبعة
- متابعة التراخيص الحكومية
- متابعة المشاريع
- متابعة العقود الإيجارية
- متابعة القضايا ومنصة تراضي
- متابعة تحديث شموس الفروع
- نظام الصادر والوارد
- متابعة الغرامات والمخالفات الحكومية

## الذكاء الاصطناعي المحلي — المراحل المكتملة
1. المساعد الإداري الذكي والأوامر العربية.
2. تحليل السجلات والمخاطر وجودة البيانات.
3. التوصيات الذكية وخطة العمل وترتيب الأولويات.
4. لوحة القرار التنفيذي، مؤشرات الأداء، الملخصات والتقارير التنفيذية.

تتم المعالجة محليًا داخل المتصفح ولا تُرسل السجلات إلى خدمة ذكاء اصطناعي خارجية.

## أهم إصلاحات الاستقرار
- مزامنة Supabase للنظامين الجديدين ضمن مساحات مستقلة.
- أزرار الصفحة الرئيسية في شاشات الدخول وداخل النظامين الجديدين.
- الإبقاء على أول 37 مخالفة فعلية من البيانات الأساسية وإزالة الصفوف التجريبية اللاحقة.
- عرض سبعة أنظمة تشغيلية وسبعة أنظمة مترابطة.
- نقل الفرص والمشروعات الحكومية أسفل الأنظمة.
- إزالة النصوص البرمجية وأرقام الإصدارات من أسفل الصفحة.
- عرض رقم الإصدار داخل الإعدادات فقط.
