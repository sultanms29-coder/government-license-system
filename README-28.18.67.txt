28.18.67 — Shomoos HR → PR workflow
- HR permission is limited to manager appointment, transfer, or termination updates.
- Every HR manager change creates a durable synced Shomoos task.
- All PR user accounts see the open task in Shomoos notifications/pending view.
- Tasks survive cloud reconciliation and stay open until PR confirms the update in the Ministry of Interior Shomoos platform.
- Notification seen-state is per user account, not shared across users on the same device.
