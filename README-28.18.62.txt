الإصدار 28.18.62

إصلاح مخصص لنظام متابعة الأعمال اليومية فقط:
- منع فقدان طلبات اعتماد المهام عند العمل المتزامن من أكثر من جهاز.
- دمج السجلات حسب آخر تعديل فعلي لكل سجل بدل استبدال كامل البيانات.
- مصالحة تلقائية بعد الحفظ لاكتشاف الكتابة المتزامنة وإعادة توحيد البيانات.
- Realtime يدمج التحديث الوارد مع التعديلات المحلية غير المرسلة بدل مسحها.
- إضافة updatedAt لطلبات إنشاء المهام عند الإرسال والاعتماد والرفض.
- الإبقاء على حذف المهام المحمي بـ tombstones.
- لم يتم تغيير منطق مزامنة أو إعدادات بقية الأنظمة.
